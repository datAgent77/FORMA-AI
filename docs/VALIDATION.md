## Known limitations
This is source ready for Editor integration, not a demonstrated working headset experience. Meta APIs were written against documented concepts but not compiled against Core 207; any release-specific adjustments must be resolved in Unity. Passthrough initialization/layer flags do not prove final compositor visibility. Room layout is manually cleared; no collision detection or boundary geometry enforcement exists. Controller gaze input, panel layout, simplistic avatar animation and font sizing need hardware usability review. The scene builder targets Built-in rendering. No hand-only operation, audio guidance, AI, advanced avatars, form correction, body tracking, Worlds or Mirror implementation exists.

History is plaintext local JSON, single profile, single writer; there is no encryption, cross-device sync, retention policy, paging or disk quota management. Unexpected process death can lose progress since the last checkpoint. Schema upgrades are skipped, not migrated. Manual counts/load use bounded increment-and-wrap controls. CI validates only pure domain C#, not Unity assemblies or Android. No store submission, release signing or SDK licensing clearance was performed.
