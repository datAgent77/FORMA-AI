# Coach asset provenance

Coaches.json is original FORMA configuration. All three presets use the same original procedural development mesh constructed from Unity primitives by StudioSceneBuilder, with distinct palettes and head accessories selected by CoachAppearance. No third-party character mesh, celebrity likeness, voice, recording or external texture is used. These are explicitly development avatars; polished character art, natural animation and validated exercise demonstrations remain a release gate. Personality changes phrasing only; safety guidance and workout transitions are shared.
