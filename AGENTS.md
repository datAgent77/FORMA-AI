# FORMA AI engineering instructions
Scope is Phase 0 and Phase 1. Keep the workout offline and deterministic. Domain code must not reference Unity, Meta, Android, networking or avatar code. Never fabricate Unity scenes, .meta files, ProjectSettings or package lockfiles. Generate these using the actual Editor, then commit them with their owning assets. Do not claim compilation, builds, device compatibility, tracking accuracy or safety validation without recorded evidence. Preserve passthrough during pause and summary. Fail closed on missing XR, passthrough, focus or tracking; never auto-resume. No raw camera/motion recording, analytics or cloud transport in Phase 1. Changes to state transitions need behavioral tests. Do not add AI or Movement dependencies until a scoped validated requirement exists. SDK upgrades require official source review, an exact package lock and Quest 3/3S smoke tests. Never commit credentials, signing keys or personal session files.
