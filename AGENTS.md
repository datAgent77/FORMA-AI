The primary consumer deliverable is a native Unity/C# MR app on Quest 3/3S. The browser/WebXR simulator is secondary developer tooling. Do not add web UI polish while native import, scene, Android build and device acceptance remain unverified. Never count .NET, HTTP, WebGL or browser results as Unity/Quest evidence. Native milestone completion requires an actual successful Unity Android build and supported-device validation.

Scope includes preserved Phase 0/1, Phase 2 A/B and the explicitly requested Phase 4 Daily Experience (A), followed by Complete Workout Loop (B) only after daily behavior is tested. Do not start Island, later relationship/habit modules, billing or an AI backend in this slice. Web acceptance and Unity/Quest acceptance must be reported separately. Work on a feature branch and do not merge automatically. Keep the workout offline and deterministic. Domain code must not reference Unity, Meta, Android, networking or avatar code. Never fabricate Unity scenes, .meta files, ProjectSettings or package lockfiles. Generate these using the actual Editor, then commit them with their owning assets. Do not claim compilation, builds, device compatibility, tracking accuracy or safety validation without recorded evidence. Preserve passthrough during pause and summary. Fail closed on missing XR, passthrough, focus or tracking; never auto-resume. No raw camera/motion recording, analytics or cloud transport in Phase 1. Changes to state transitions need behavioral tests. Do not add AI or Movement dependencies until a scoped validated requirement exists. SDK upgrades require official source review, an exact package lock and Quest 3/3S smoke tests. Never commit credentials, signing keys or personal session files.

The local web simulation is authorized test tooling, not a production or AI backend. Link the actual Domain/Product/Storage C# sources instead of duplicating business rules in JavaScript. Label synthetic XR signals, clock jumps and history. Keep it loopback-only and isolated from real device profiles. Web success never clears Unity/Quest acceptance gates.
